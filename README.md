# Scrollable Tooltips Port

An unofficial port of Scrollable Tooltips by Sk1er for newer Minecraft versions.

<img src="https://i.ytimg.com/vi/MD3MbU1q5Wg/maxresdefault.jpg" alt="Scrollable Tooltips" width="600">

This project is not affiliated with or endorsed by Sk1er LLC.

## Features

* Scroll through long item tooltips using the mouse wheel.
* Easily read tooltips that are too large to fit on the screen.
* Client-side mod.
* Lightweight and focused on improving tooltip readability.

## Requirements

* [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)

## Installation

1. Install Fabric Language Kotlin.
2. Download the latest `.jar` from the Releases section.
3. Place the `.jar` file into your Minecraft `mods` folder.
4. Launch Minecraft.
